# 🖐 Welcome to my personal portfolio!

In this portofolio, I want to archive my projects that I made in programing languages while learning them. I am starting with python, and as time will go on, I want to add others also.

### Strucutre of the projects
I designed the projects in this repository so that I could finish them in a few hours, so they're short-term projects. I wanted to learn something from each of them, so I tried to make the next project bigger, with something new that I have to learn, to make progress in my learning journey.

### Using of AI
I am using AI in two ways:
1. For most project, I writing the basic code structure by myself. When I am stuck, with something, I tried to fix it by myself, but when I didn't succes, I disscues the code with an AI, to help me fix the error, and explain me where I made the error.
2. In some cases, where I don't feel like I want to learn so much, but rather discover new things, I am using AI as a colleque, with suggesting my new ideas, what I can do, and me making them and sending the sharing the progrees with AI.

In most projects in this repo, am using way one, because I want to learn as much as possible from them, because they are the basics.
